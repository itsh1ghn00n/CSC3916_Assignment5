Assignment Five
This React application includes:

- User signup and login with JWT authentication
- Protected routes for movies, search, and reviews
- Display of top-rated movies (sorted server-side)
- Movie detail page with:
  -  Poster image
  - Actors and roles
  - Average rating (aggregated)
  - Review grid
- Ability for logged-in users to submit reviews
- Search functionality by movie title or actor (extra credit)
